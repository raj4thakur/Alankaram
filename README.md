# Alankaram Studio Operations Dashboard

A single-page operations dashboard prototype for Alankaram, an artisan furniture studio. The interface brings production cells, timber and material intelligence, tooling health, quality control, customer orders, and operational rules into one view.

## Features

- Studio command center with efficiency, output, quality, and tooling metrics
- Production cell monitoring with expandable operational details
- Timber and material inventory intelligence
- Tooling and machine health tracking
- Quality-control alerts and rework monitoring
- Customer order status and delivery-risk tracking
- Rule configuration and what-if operational simulations
- Responsive layout for desktop and smaller screens

## Run locally

This is a static HTML prototype with no build step or dependencies.

1. Clone the repository:

   ```bash
   git clone https://github.com/raj4thakur/Alankaram.git
   cd Alankaram
   ```

2. Open `index.html` in a browser, or serve the directory with any static HTTP server:

   ```bash
   python3 -m http.server
   ```

   Then visit <http://localhost:8000>.

## Project structure

- `index.html` — primary dashboard page
- `index1.html` — alternate dashboard page/prototype

## Notes

The dashboard currently uses illustrative sample data and inline styling/scripts. It is intended as a visual and interaction prototype for future integration with live studio operations data.
